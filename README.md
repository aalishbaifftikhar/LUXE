# LUXE

Premium Women's Fashion E-commerce Frontend

## About the Project

LUXE is a modern women's fashion website featuring elegant design, premium fashion imagery, and interactive shopping interface elements.

## Features

- Scroll-based animated hero section
- Women's fashion categories
- New arrivals and product color swatches
- Interactive wishlist
- Shopping bag
- About and Contact pages
- Privacy Policy and Terms & Conditions

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Status

Frontend demonstration project. Backend, authentication, and payment processing are not implemented.
